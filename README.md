# Customer Churn Prediction Using Machine Learning

## Project Overview
This project focuses on customer churn prediction in the telecommunications industry using machine learning techniques.

The main goal is to analyze customer behavior, identify factors associated with customer churn, and investigate how machine learning methods can support customer retention strategies.

## Project Objectives
- Analyze customer churn patterns.
- Explore the relationship between customer characteristics and churn.
- Review machine learning algorithms for churn prediction.
- Plan a comparative evaluation of predictive models.

## Dataset
**IBM Telco Customer Churn Dataset**

- 7,043 customer records
- 21 attributes
- Target variable: Churn
