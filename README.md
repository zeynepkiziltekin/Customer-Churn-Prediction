# Customer Churn Prediction Using Machine Learning

This project focuses on analyzing customer churn in the telecommunications industry using machine learning techniques.

## Project Objectives
- Analyze customer churn behavior.
- Explore factors related to customer churn.
- Review machine learning methods for churn prediction.

## Dataset
IBM Telco Customer Churn Dataset.

## Tools
- Python
- Google Colab
- Pandas
- Matplotlib
- Scikit-learn

## Project Status
Dataset analysis and exploratory data analysis have been completed. Machine learning model implementation is planned for the next stage.
